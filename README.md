## Deploy
Upload the CONTENTS of this folder to the ROOT of your GitHub repository. Do not create a nested `Portfolio-Karthikeyan-M-V5/Portfolio-Karthikeyan-M-V5` folder.

GitHub → Settings → Pages → Source: GitHub Actions.

The workflow is in `.github/workflows/pages.yml`.

## Profile URLs
Edit `assets/js/main.js` and replace the `PROFILE_URLS` values with your actual public profile URLs.
