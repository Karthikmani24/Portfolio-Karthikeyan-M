# Karthikeyan M — Cybersecurity Portfolio V2

A GitHub Pages-ready static portfolio with:

- Lighter premium burgundy/wine theme
- Cybersecurity-inspired animations
- SOC/GRC visual status panel
- Responsive mobile navigation
- Certification icon cards
- Click-to-reveal contact UI
- Dedicated Forum page
- GitHub Discussions as the forum backend
- GitHub Actions deployment to GitHub Pages

## Before publishing

1. Replace `YOUR_EMAIL_HERE` and `YOUR_PHONE_HERE` in `assets/js/main.js`.
2. Replace `resume.pdf` with your actual current resume PDF.
3. Enable GitHub Discussions in repository Settings.
4. Create discussion categories.
5. In Settings → Pages, select **GitHub Actions** as the source.
6. Push to `main`.

## Important

The contact reveal is only a UI privacy feature. Public GitHub Pages code is inspectable. Never place secrets, API keys, passwords, customer data, internal IPs or confidential security evidence in this repository.
